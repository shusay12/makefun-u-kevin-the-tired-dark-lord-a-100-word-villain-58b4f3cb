# The Tired Dark Lord: A 100-Word Villain Monologue

A tiny deterministic program for the make.fun bounty
"The Tired Dark Lord: A 100-Word Villain Monologue" (u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb).
Running `main.py` (Python 3.13, standard library only, no network) writes one
100-word monologue — a fantasy villain who is secretly just very tired — to
`/output/entry.txt`. It runs identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> Hero. Sit — no, not the throne, the stool. The one with the wobble. You came to slay me, I know. The prophecy, the sword, the parade. Where did I put the — ah. Never mind. Three centuries of monologues, and nobody ever lets me finish the — sorry, what was I saying? Right. My kingdom. I raised the dead legions, cursed the harvest, kept the receipts. And for what? So some farm boy with destiny could — hmm. The torches are dying. Take the crown, hero. It's heavy. Give me five minutes. The dark can wait. It always does.

Exactly 100 words, 521 characters — inside the 1–600 character gate. The
tiredness lives in the rhythm, the pauses and the small deflections (the lost
thread, the wobbling stool, the dying torches, asking for five minutes), never
in a plain statement that the villain is weary. The program asserts the entry
is exactly 100 words and 1–600 characters before writing it.

## Layout

- `main.py` — the entry program
- `run1/out/entry.txt`, `run2/out/entry.txt` — two local runs, byte-identical
